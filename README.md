# Pullwise

A World of Warcraft add-on that turns combat logging on when a Mythic+ key starts and turns it off
when the key ends. It does nothing else: no windows, no messages beyond one line in chat, no data
sent anywhere.

The combat log is the file the game writes to `World of Warcraft/_retail_/Logs/`. Tools outside the
game, such as the Pullwise Helper, read that file after the key.

Free, with its code public, under the MIT licence.

## Installing

From CurseForge, Wago or WoWInterface, or download the zip from Releases and unzip it into
`World of Warcraft/_retail_/Interface/AddOns/`.
